# AlUla Agriculture Center portals

One link, two portals:

- `auction/` — AlUla Date Auction 2026 (single-file page built from `alula-date-auction/` in the Kareem workspace).
- `survey/` — Dates & citrus production survey (`farm-production-survey.html`).

`index.html` is the landing page that opens either portal. Static files only, served by GitHub Pages.
To update a portal, replace its `index.html` with the new build and push.
